    What happened, in order

    1. The new link looked quicker, because on an empty road it is.
    2. Drivers tried it, got home sooner, and told their estimate so.
    3. More drivers switched — until nearly everyone used both narrow bridges.
    4. Queues stood behind both bridges instead of one.
    5. Every route now crosses a queue. Including the ones nobody changed.

    The new link never jammed. Look at it — it is the emptiest road on the map. It did not add traffic. It changed where traffic chose to go.

    Every driver crosses one narrow bridge, then takes a long ring road. The dotted link would let them use both bridges and skip both rings — about a minute quicker, on an empty road.

    Braess's paradox

    Adding a road to a network can make every journey on it longer — not because the road is slow, but because it changes what each driver decides is best for them. Every one of those decisions is correct. The result they add up to is worse for all of them.

    It is not a law that new roads make traffic worse. In this same network, with the same simulation, light traffic makes the link a genuine improvement . Whether it helps depends on how close the roads already are to their limits.
