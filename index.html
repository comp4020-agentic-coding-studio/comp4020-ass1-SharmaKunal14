Nothing hidden

Here is every calculation.

  1. Cars on each narrow road(4,000 + 0) ÷ 2 = 2,000
  2. Time on each narrow road2,000 ÷ 100 = 20 min
  3. Old route20 + 45 = 65 min
  4. Shortcut route20 + 20 = 40 min
  5. Average of all 4,000 trips4,000 × 65 ÷ 4,000 = 65 min

You found the paradox

Each driver saved time by switching. Together, they added 15 minutes.

With no shortcut, the average was 65 minutes. When all 4,000 drivers use it, both narrow roads take 40 minutes, so the shortcut trip takes 80 minutes. This is Braess’s paradox: a new option can make the whole network worse.
