      Braess's paradox

      Adding a road to a network can make every journey on it longer — not because the road is slow, but because it changes what each driver decides is best for them. Every one of those decisions is correct. The result they add up to is worse for all of them.

      It is not a law that new roads make traffic worse. In this same network, with the same simulation, light traffic makes the link a real improvement. Whether it helps depends on how close the roads already are to their limits.
